This page reports the values of window/screen/scroll position and size properties. Run it in various browsers and compare (or diff the downloaded JSON).

Tests run automatically on load. Some properties only differ once the page is in a particular state (e.g. body.scrollTop vs documentElement.scrollTop only diverge after scrolling; screenX only changes when the window moves). To capture those, put the window in the state you want (scroll, resize, or move it), then click Re-run tests before downloading.
